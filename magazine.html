A Demonstration of
Shaped Text
Knuth–Plass Line Breaking in Arbitrary Containers
I — Circle Wrap
Text Flows Around
Any Obstacle
The line width function accepts a line number and returns the available width. By subtracting the circular obstruction from each line's available space, text flows naturally around any shape.
lineWidths(n)
= f(geometry)
II — Diamond Form
Expanding & Contracting
Lines start narrow, widen to the middle, then narrow again — forming a diamond. The optimizer distributes text evenly across all line widths.
The algorithm considers every possible arrangement of words
and selects the one that minimizes a global cost function.
III — Hourglass
Pinch & Release
Wide at the edges, pinched in the center. The inverse of the diamond demonstrates how the algorithm handles dramatic width changes gracefully.
IV — Sinusoidal Margins
Riding the Wave
Both left and right margins follow sine curves with different phases, creating an undulating text column.
V — Circular Fill
Text in a Circle
Each line's width is computed from the chord length at that vertical position within a circle. The text fills the circular boundary perfectly.
