# Test corpus

`typst/` is generated by `tools/typ2tsm.mjs` from the Typst test suite
(https://github.com/typst/typst, Apache-2.0): the shared pure-markup subset of
its test cases, extracted at case granularity and lightly filtered (no Typst
code, math, labels/refs, or term lists — see the extractor's reject list).

The corpus is smoke/golden input for OUR engine — Typst's pixel references are
not portable across renderers. Run it with:

    node tools/corpus-run.mjs

Every finding here should graduate into a hand-written fixture under
`test/fixtures/` (testing.md §1).
