# TeX-Grade Web Typesetter

## Project Overview

A client-side JavaScript/TypeScript typesetting library implementing Knuth-Plass optimal line breaking with Liang hyphenation for web. The goal is to produce TeX-quality paragraph typesetting in the browser, targeting a personal blog (https://www.cnblogs.com/tmzbot, future GitHub Pages).

**Proof of concept repo**: https://github.com/iamstupid/js-linebreaker

## Architecture

All client-side. No server-side processing. TypeScript source in `src/`, bundled with esbuild into a single IIFE (`dist/typesetter.js`) for browser use.

### Build Command

```bash
npx esbuild src/index.ts --bundle --outfile=dist/typesetter.js --format=iife --global-name=Typesetter --target=es2020 --platform=browser --define:define=undefined
# Remove "use strict" if present:
sed -i '1{/^"use strict";$/d}' dist/typesetter.js
```

### Demo Pages

- `index.html` — interactive editor with sliders for cost function parameters
- `magazine.html` — irregular shape container demos (circle wrap, diamond, hourglass, wave, circle fill)

Both are generated by inlining the bundle into template HTML via `%%BUNDLE%%` replacement.

## Core Algorithm

### Line Breaking (src/linebreak.ts)

1D DP over breakable block positions with sparse 2D state `dp[i] = [(line_count, cost)]`.

**Key design:**
- Virtual start block prepended at index 0
- Breakable positions precomputed into `bkIdx[]` array
- Cursor in breakable-index space tracks parent of best transition
- Search window: `cursorB ± cursorSearchRange` (default 5) breakable positions
- Pruning: keep line counts within ±1 of best
- Fallback: if cost is INF, retry with search range 10 → 20 → 50 → ∞

**Cost function** (font-size invariant):
```
x = slack / totalSpace
if x < -shrinkThreshold: return INF
if x < 0: mapped = c * (1/(1+x) - 1)    // perceptual shrink mapping
else:      mapped = x
cost = mapped^n
```

**Recommended parameters** (for avg >6 words/line):
- Exponent (n): 3
- Hyphen penalty: 0.70
- Shrink threshold: 0.37
- Shrink coeff (c): 0.6

### Hyphenation (src/hyphenate.ts)

Uses `hyphen` npm package (Liang's algorithm with TeX patterns). English only currently. Wraps `hyphenateSync` with soft-hyphen splitting.

### Text Measurement (src/measure.ts)

Canvas `measureText()` — browser measures with the same engine it renders with. Bigram-aware with `font#size#weight#italic` cache keys.

### Block Structure

```
struct linebreak_block {
  width, breakPenalty, breakWidth, spaceWidth, height
  styling: TextStyling
  content: { type: 'text', text } | { type: 'block', block: InlineBlock }
}
```

Block types:
- **Phoneme**: breakPenalty=INF, width=measured, breakWidth=0, spaceWidth=0
- **Hyphen point**: breakPenalty>0, width=0, breakWidth=width('-'), spaceWidth=0
- **Existing hyphen break** (e.g. after "bit-" in "bit-wise"): breakPenalty=0, width=0, breakWidth=0
- **Space**: breakPenalty=0, width=spaceWidth=width(' ')
- **CJK char**: breakPenalty=0, width=1em, spaceWidth=0.1em
- **Opening punct**: [breakable 0.5em space, sw=0] + [unbreakable 0.5em glyph]
- **Closing punct**: [unbreakable 0.5em glyph] + [breakable 0.5em space, sw=0]
- **Consecutive punct**: compressed (spaces between removed, no break between)
- **Em dash pair ——**: unbreakable, width=2em
- **Ellipsis pair ……**: unbreakable, width=2em
- **CJK-Latin boundary**: breakable, width=0.25em, sw=0.25em
- **Indent**: unbreakable, width=1em (×2 for CJK 2em indent)

### Negative Slack Handling

Lines can slightly overflow (up to `shrinkThreshold × totalSpace`). The renderer computes per-line slack and applies negative `word-spacing` CSS to compress overflowing lines. This applies to ALL lines including the last.

## New Type System (src/types2.ts) — IN PROGRESS

Unified class-based styling model replacing the old `TextStyle` interface.

### TextStyling

Each block carries a `TextStyling` with:
- `baseClass: bigint` — bitset of engine-defined classes (bits 0-255)
- `classes: Set<number>` — dynamically generated class IDs (≥256)
- `inlineStyle: InlineStyle | null` — CSS property overrides

**Engine-defined class bits:**
```
0  CLS_LATIN        7  CLS_CJK_EMPH     14 CLS_CJK_SPACE
1  CLS_CJK          8  CLS_PUNCT_OPEN   15 CLS_PUNCT_SPACE
2  CLS_EM           9  CLS_PUNCT_CLOSE
3  CLS_BOLD         10 CLS_INDENT
4  CLS_BOUNDARY     11 CLS_HYPHEN
5  CLS_HAS_STYLE    12 CLS_SPACE
6  CLS_CODE         13 CLS_LINK
```

### StyleManager

Registry mapping dynamic class names ↔ IDs ↔ CSS styles. Used for content-defined styles (e.g. markup directives that create unique style combinations).

### InlineBlock

Recursive structure for links, math, etc.: `{ tag, attrs, children: LinebreakBlock[] }`. Rendered as their own DOM element wrapping child blocks.

## Span Tree Builder — NOT YET IMPLEMENTED

Efficient HTML generation using class hierarchy nesting:

**Algorithm:**
For each block in a line, compare its `TextStyling` classes against the current open span stack:
1. **Same classes** → append text to current span
2. **Superset of current** → open new child span with diff classes
3. **Not superset** → close spans until current is a subset, then open new child

This produces minimal nested HTML like:
```html
<span class="cjk">这是<span class="bold">粗体</span>和<span class="em">斜体</span></span><span class="latin">text</span>
```

**Spacing adjustment** applied as inline styles:
- CJK runs: `letter-spacing` (computed from 0.1em stretchable space per char)
- Latin runs: `word-spacing` (computed from total stretchable space)
- Punctuation spaces: absorbed into adjacent spans

## CJK Support (src/cjk.ts) — IN PROGRESS

Character classification and block emission following GB/T 15834 for SC horizontal typesetting.

**Key rules:**
- CJK chars: 1em width, 0.1em stretchable inter-char space (sole justification source for CJK-only lines)
- Punctuation compression: consecutive compressible puncts merge spaces
- Punct compressible spaces are NOT stretchable
- Line-start compression: opening punct's leading 0.5em is breakable (vanishes at line start)
- Line-end compression: closing punct's trailing 0.5em is breakable (vanishes at line end)
- CJK-Latin boundary: 0.25em thin space (breakable, stretchable)
- Paragraph indent: 2 × 1em unbreakable blocks (not CSS padding)
- No italic for CJK; use text-emphasis: filled dot
- Em dash pair and ellipsis pair are unbreakable

## Markup Language — NOT YET IMPLEMENTED

Markdown-compatible with Typst-like extensibility:
- Standard: `*italic*`, `**bold**`, `` `code` ``, `[text](url)`, headers, separators
- Custom directives for programmable features
- Custom math syntax (simpler than LaTeX, AMS Euler font) — future
- Blog-focused: the typesetter owns paragraph-level content; block-level structure (headings, code blocks, images, lists) handled by the blog framework

## Font Choices

- **Body**: Crimson Text (Latin), Source Han Serif / Noto Serif CJK SC (CJK) — both SIL OFL
- **UI**: Inter (to be replaced with something more distinctive)
- **Code**: JetBrains Mono
- **Math** (future): AMS Euler
